The Lads' Local — modern blue theme

This package contains the existing Arcade Edition with a refreshed light blue and white visual theme.

To deploy: unzip, drag the lads-local-pwa folder (not the ZIP) into Netlify Deploys. Refresh the installed phone app; if the old theme remains, clear its site cache or reinstall the PWA.

This is a styling upgrade. Supabase tables and existing content are unchanged. Test on your live site before Friday.
