# Complimentary DJ access

Michael's verified platform-owner account and Coombe Social Club's Coventry venue have permanent full DJ software grants with no expiry and no payment requirement. No Stripe subscription or payment method was created for them.

Hosted sign-in checks the grant table through the trusted DJ Edge Function. Personal grants apply to the signed-in host. A venue grant applies only to users with verified authority to manage that venue; it does not make visitors hosts. Coombe's registered hosts and authorised venue managers can use its venue grant. Grant table privileges are revoked from browser roles and protected by RLS. Never infer authorisation from editable user_metadata, a client-side email check or localStorage.

The hosted flow bypasses checkout for complimentary access and opens a shared room for authorised music files or the included original samples. The independent Python LAN pilot remains a separate password-based tool. Complimentary software access does not supply commercial music rights.
