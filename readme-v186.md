# The Local v186 — Arcade visual rebuild (phase one)

Full website ZIP based on v185. Adds a consistent premium emerald/gold visual treatment across the 14 existing browser games, clearer active game selection, improved small-screen layouts, optional sound effects (off by default), reduced visual effects control, and optional full-screen play. Sound is a simple interaction tone, not simulated ball/dart sounds. Existing gameplay, AI opponents and online Supabase infrastructure are unchanged.

## Important limits
This is a visual/accessibility pass, NOT a full realistic rebuild of all 14 engines. Eight-ball and snooker remain turn-based challenges, not fully physically simulated matches. Multiplayer remains unverified. Do not claim realistic 3D graphics or competitive multiplayer.

## Install
Back up your live site. Upload this entire ZIP to the main The Local Netlify site, not the separate sales engine. No SQL migration. Test all 14 games on mobile and desktop, sound toggle, fullscreen, restart and existing online pages.
