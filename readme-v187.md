# The Local v187 — Mobile-first launch and sharing assistant

## New
- Five focused builder steps: Venue, Features, Preview, Go live, Share.
- Beginner-friendly launch readiness checklist, with manual confirmation before publishing.
- Published app sharing by phone native share, copy link, WhatsApp and email.
- AI writing and coaching tools remain available in the collapsed More tools area.
- No new SQL needed. Existing publishing RPCs remain unchanged.

## Important
Sharing is enabled only after a successful publish. The public link uses the existing venue slug and venue-app.html route. This build does not auto-publish or claim AI can verify external site availability. Notification delivery still needs separate setup.

## Deploy
