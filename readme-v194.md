# The Local v194 — Compact Logo & Site-Wide Visual Refinement

Based on the complete v193 website. Adds `local-v194-refinement.css` as the final stylesheet on all seven standalone HTML pages with a `<head>` section: index, games room, guest, venue app, for venues, community competitions, and secure tables.

## Changes
- Shrinks the oversized full gold logo in the main header, login gate, venue sales header, admin, preview mockups and hero.
- Applies consistent text rendering, accessible keyboard focus, responsive image constraints, and restrained hover effects.
- Keeps the emerald/gold identity, with subtle unified radii and card border tones.
- Includes reduced-motion support and tighter logo sizing for mobile.
- No changes to authentication, database, payments, games engines or venue publishing.

## Caveats
- This is a stylesheet-based polish pass, not a complete redesign of every screen or a verified conversion/retention improvement.
- The separate Coombe Social Club project is not modified.
- Browser and device visual QA is still required, especially on legacy dynamically rendered screens.

## Deployment
Back up the current Netlify deployment and upload the complete ZIP. Clear cache or hard-refresh if the previous logo remains.
