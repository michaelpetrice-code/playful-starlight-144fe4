The Local v37 — Immersive Table Lounge

Adds a visual pub table with member initials based on table chat activity, invite/share button, table photo gallery (HTTPS photo links), emoji composer, message reactions, and jump links to table games. Existing v36 features preserved.

Note: Presence is inferred from messages, not real-time attendance. Image uploads to cloud storage, live multiplayer game synchronisation and cross-device message expiry require backend work.
