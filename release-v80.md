# The Local v80 — Gameplay Reliability Upgrade

- Battleships now plays against a computer opponent with two independently generated fleets, automatic counterattacks, ship hit tracking and win/loss detection.
- Block Drop has pause/resume and stops its interval when removed from the Games Room.
- Word Search now only lists words actually placed in the generated puzzle.
- Existing pool/snooker physics, darts, Klondike, Ludo, multiplayer and quiz are retained.
- Existing application data and server configuration remain unchanged.

## Limits
This is a substantive improvement to several game engines, not a full commercial-grade replacement for all games. Pool/snooker remain 2D arcade approximations, and online multiplayer needs a configured backend and testing with two signed-in accounts. Test on a staging Netlify site first.
