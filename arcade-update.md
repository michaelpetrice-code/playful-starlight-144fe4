# The Lads’ Local — Arcade Update

Adds an Arcade tab with Battleships (solo hidden fleet), Crossword Challenge (five clues), Word Search (six hidden words), and Blocks (place pieces and clear lines).

All four games run in the browser on phones or Windows. Progress is stored on each device. Completed games post points to the existing shared leaderboard when signed into a group; in demo mode scores are local. Battleships and Blocks are solo games, not head-to-head multiplayer.

## Install
Extract ZIP. Upload the **lads-local-pwa** folder to Netlify Deploys. Reload or close/reopen installed phone app. No SQL change required.

## Test
Visit Arcade, tap each game. Complete a challenge, then check the Lads leaderboard. The weekly Pool/Snooker/Darts boards remain separate and unaffected.
