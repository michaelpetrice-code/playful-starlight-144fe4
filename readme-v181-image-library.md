# The Local v181 — Image & Icon Library

Upload the entire ZIP to the main The Local Netlify project. No SQL changes required beyond v178/v180 setup.

The Builder now includes a searchable, beginner-friendly library on venue logos and individual cards. It contains 11 existing local photographs and 12 bundled original simple pictogram tiles. Owners can still upload their own JPG/PNG/WebP images. Choosing an item updates the preview immediately, but changes must be saved/published.

The library uses existing bundled site photos and locally generated icon tiles, with no external stock photo service or API key. The same photo may be used by multiple venues. The URLs use the current website origin: if you later change the main domain, previously saved image URLs may need migration. Do not use the built-in photos as a venue's actual premises unless they genuinely depict that venue.
