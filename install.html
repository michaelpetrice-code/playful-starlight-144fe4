Install on your device

Android — Chrome

Open The Local in Chrome, tap the browser menu (⋮), then choose Install app or Add to Home screen if offered.

iPhone — Safari

Open The Local in Safari, tap Share, then Add to Home Screen. Follow the on-screen prompts.

Computer

Open The Local in a compatible browser. Use its install option if available, or bookmark the site.
