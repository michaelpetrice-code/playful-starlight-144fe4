# The Local v112 — Premium Arcade Polish

Preserves the v111 app and existing game engines. Adds a dark emerald/gold arcade design, keyboard focus outlines, responsive two-column mobile game cards, reduced-motion support, optional short interface sound (off by default), and a session-only count of game launches.

This is a UI and interaction upgrade, NOT a claim that cue physics, game AI, leaderboards, or online multiplayer have been newly implemented or independently verified. Existing functionality remains subject to staging testing.

Deploy the contents of this folder to a separate Netlify staging site. Test games, audio preferences, mobile layout and existing Supabase connections before production.
