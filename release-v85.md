# The Local v85 — Marketplace teaser examples

Adds six clearly labelled **sample listings** to Buy, Sell or Give Away: bicycle, chest of drawers, garden tools, board games, coffee machine, and children’s books. Each includes illustrative graphics, sample prices and descriptions. They are never inserted into the database, never attributed to real sellers, and cannot be purchased or messaged. Real listings remain separate, and the sample section provides a button to create a real listing.

The samples appear for all visitors in the marketplace (except the “My listings” view). Existing marketplace image uploads, messages, listing search, authentication, games and admin features are retained.

Upload the ZIP to Netlify. No Supabase schema changes needed for the teasers.
