# The Local v185 — Flagship Arcade Challenges

Complete main-site ZIP based on v184. Adds 3 flagship local single-player challenge modes to the existing practice room: Eight-Ball (turn-based tactical rules with groups, fouls, eight-ball finishing, difficulty-based computer), Snooker (red/colour scoring, clearance sequence and computer turns), and 501 Darts (target-based scoring, bust and double-out, computer opponent). All 11 existing games retained, including the pool physics practice table. New games use the existing rule-based coaching panel and browser-local stats.

## IMPORTANT LIMITATIONS
These are **turn-based browser challenges**, not full simulation-quality 8-ball/snooker physics engines or official referee implementations. Snooker foul and free-ball rules are simplified. Darts is target selection, not motion-controlled throwing. Computer opponent is rule-based probability, not machine learning. Existing online infrastructure remains untouched; online competitive multiplayer is **not added or certified**. Local scores are not verified.

## Deploy
Upload full ZIP to the MAIN The Local Netlify site. No SQL needed. Hard refresh. Open Games Room → Improved Arcade, then choose flagship game. Test on mobile before release.
