THE LADS' LOCAL — MOBILE NAVIGATION & GAMES UPDATE

WHAT'S NEW
- Fixed bottom navigation: Home, Chat, Events, Tournaments, Arcade, More.
- More drawer: Rounds, Photos, Football, Kitty, Quiz, Games, More Games, Leaderboard, Alerts, Install, Account.
- Four extra phone games: Memory Match, Higher or Lower, Lads' Sports Quiz, Guess the Number.
- New games use the existing game_score mechanism to add points to the general Lads leaderboard.
- Pool, Snooker and Darts weekly tournaments remain separate and unchanged.

DEPLOY
1. Extract the ZIP.
2. Drag the lads-local-pwa folder onto Netlify Deploys.
3. Wait for Published, then reopen the installed app.
4. If the old navigation persists, close/reopen the app and clear the site's cached data if needed.

No new Supabase SQL required. Existing groups, messages, events and tournament data are not changed by the theme update.

IMPORTANT
This package has passed JavaScript syntax checks but has not been live-tested against your Supabase project or on real devices. Higher or Lower is a casual card-guessing game, not gambling.
